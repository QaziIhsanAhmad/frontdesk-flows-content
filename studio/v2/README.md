# FrontDesk Flows Reels v2 – real n8n demo pipeline

Every Reel shows a **real n8n run**: the trigger (website form, booking screen or schedule), each node executing on the
real n8n canvas, and the real result (emails delivered over SMTP to a demo inbox). Only these parts are simulated, and
every video labels them on screen: the AI model's answer (sandbox endpoint), AI outages, and the Google Sheets row (pinned data).

## Layout
- `setup.sh` – installs n8n 1.95.3, Playwright, Kokoro TTS, starts n8n + the sandbox (demo clinic site, AI sandbox, SMTP inbox)
- `sandbox/` – `server.py` (ports 80 + 1025) and `site/` (Harbourline Physio demo form + booking screen)
- `workflows/` – the n8n workflows used in the videos (product sample, no-show, reviews, reminders)
- `rec2.js` – records a take: n8n canvas (2560x1600 screencast) + trigger page + node timings + 2.5x NDV panels
- `build.py` – turns a take + `reels/<id>.json` script into frames/audio (voice: Kokoro af_heart, music: `music.py`, original)
- `render2.js` + `stage2.html` – renders 1080x1920 frames; `cover2.js` – cover image
- `scenarios/` – take definitions; `reels/` – Reel scripts (hook, scenes, captions)

Scene types: hook, form, split (trigger + canvas side by side with a live timer), run (camera follows a pulse along the
real canvas, step chips, SIMULATED tags), panel (2.5x node close-up), card (real prompt excerpt), result (inbox / list), ba, cta.
Layouts: default window, `"layout": "bleed"` (full-screen cinematic canvas).

## Make a Reel
```
bash studio/v2/setup.sh                 # once per machine
python3 prep.py scenarios/<take>.json && node rec2.js scenarios/<take>.json
python3 build.py reels/<id>.json && node render2.js <id>
node cover2.js out/<id>_cover.jpg "REAL n8n WORKFLOW" "Headline<br><span>green part</span>" "DM FLOW · free sample" work/<id>/coverbg.jpg
```
Then add it to `queue.json` with a NEW id (never reuse an old id/guid – that is what prevents duplicate posts).

## Rules
- Every video: hook in the first second, the real trigger, the real canvas running, the real result, before/after, "DM FLOW".
- Vary the presentation (window / bleed / split / inbox-first) and the scenario (patient, clinic event, branch taken).
- Label every simulated step on screen and in the caption.
- Music is generated by `music.py` (original, owned) – no third-party audio.
- Instagram via Make uses `thumb_offset` 1500 ms as the cover, so the hook at 1.5 s is designed to work as the cover.
